# 活动规则与发布

信息板块的四栏内容可分别发布，也可通过「一键转发」按固定顺序发布。发布依赖 Koishi 连接，连接不可用时返回失败结果。目标群在设置页「信息」类别中启用，推送开关在页面顶部。

## 活动规则

活动规则栏为纯文本编辑区，修改后自动保存，没有保存按钮。发布时按原文发送，不附加图片。文本为空时，「发布活动规则」禁用。

规则内容由活动组织者填写，程序不做格式处理；发布内容与编辑区中的文本一致。

## 目标群

目标群列表位于设置页「信息」类别，包含群 ID、展示名（可选）与启用开关。发布的群就是该页里「启用」的那些；信息板块不提供勾选入口。

「刷新群列表」同样在该页执行，向 Koishi 查询群列表并并入本地配置。新并入的群默认不启用。查询结果需要 Koishi 返回后才会并入；Koishi 未连接时提示刷新失败。

群列表的增删与展示名说明见 [信息类别与目标群](../settings/info.md)。

## 逐栏发布与一键转发

四栏各有独立的发布按钮，仅发布本栏内容。栏内无可发布内容（符卡 GIF 集为 0 张、当前 Boss 没有符卡、活动规则为空）或该栏正在发布时，按钮禁用。

发送前执行预检：检查文件存在、可读且非空。预检不通过时不发送，避免发出空图或缺少内容的消息。

![各栏发布按钮与发布结果对话框](images/info-publish-1.png)

「一键转发」按以下固定顺序发布四栏：符卡 GIF 集 → 符卡猜测情况表 → 创作者剩余未被猜测符卡数表 → 活动规则。该顺序不可调整。

各项独立执行；任一项失败后停止后续项，不再发送。结果对话框逐项列出成功或失败及原因，未发送的项单独列出。存在失败项时，对话框提供「只重试失败项」，仅补发失败项。

未启用任何目标群或正在发布时，「一键转发」禁用。

符卡猜测情况表与创作者剩余表以图片消息发送；符卡 GIF 集与活动规则以合并转发发送。

## 自动推送

页面顶部的「猜测表变化自动推送」默认关闭，勾选状态持久保存。启用后：

- 仅对符卡猜测情况表生效，创作者剩余表不在推送范围内。
- 仅在表内容实际变化时推送；无关数据变化不触发。
- 连续变化在约 1.5 秒的防抖窗口内合并为一次发送。
- 成功时不显示结果；失败时显示结果对话框，且不自动重试。
- 目标群为设置页启用的群。未启用任何群时仅记录日志，不显示对话框。

通过任一入口发布该表（「一键转发」或本栏发布）时，已排定的自动推送会被撤销；发布期间产生的表变化在发布结束后补发一次。

## 发布失败的原因

Koishi 未连接：结果中说明当前没有可用的连接。应检查 [WebSocket 状态面板](../run/websocket.md)。

未启用目标群：需在「设置 → 信息」里启用至少一个目标群。

文件缺失或为空：通常为 GIF 集导入后原目录被移动、重命名或删除。

等待 Koishi 回执超时：按失败处理，超时约 3 分钟，不自动重试；详细记录见 [日志](../run/logging.md)。
