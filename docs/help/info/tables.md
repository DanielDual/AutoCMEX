# 两张统计表

两张统计表用于展示当前 Boss 的猜测进度，并以图片形式发布到活动群。两张表的数据均来自猜测板块，不需要在信息板块填写。

## 符卡猜测情况表

该表包含当前 Boss 的全部符卡，共三栏：创作者、符卡编号、符卡名。编号为该符卡在当前 Boss 内的排列序号，从 1 开始。

![猜测情况表（已猜出行染绿）](images/info-tables-1.png)

已猜出的符卡整行染绿，其余行保持默认样式；判定与标记规则见 [猜测文本与回应规则](../guessing/syntax.md)。未猜出的符卡，创作者栏为空。该栏为空是发布时的遮罩：表格会发布到群内，提前显示创作者等于公布答案。

表内行数等于当前 Boss 的符卡总数。行按 Boss 内顺序排列，不按创作者分组。

## 创作者剩余未被猜测符卡数表

该表按创作者分组，共两栏：创作者、剩余未被猜测符卡数。剩余数为该创作者名下的符卡总数减去已猜出数；总数本身不出现在表中。

![创作者剩余表](images/info-tables-2.png)

剩余为 0 的行整行染绿，表示该创作者名下的符卡已全部猜出。创作者栏为空的符卡无法归属到具体创作者，不计入该表；因此两张表的行数可能不一致。

表中仅包含当前 Boss 中存在符卡的创作者。

## 数据来源与刷新

两张表均读取猜测板块的当前 Boss。切换 Boss 后两表同时切换；标记「已猜出」、修改符卡名或修改创作者后，表自动刷新，无需重新打开页面。

由于两表跟随当前 Boss，切换 Boss 后应确认表内符卡名与行数属于当前 Boss，再执行发布。

## 发布与自动推送

每栏有独立的「发布该表」，只发布本栏内容。图片尺寸按内容自适应生成；预览与发布使用同一份数据。栏内无数据行或正在发布时，按钮禁用。

两张表均按整表出图，行数较多时图片随之变长，不会被截断。各栏发布互不影响。

勾选页面顶部的「猜测表变化自动推送」后，仅符卡猜测情况表在内容变化时自动发布，创作者剩余表不在推送范围内。自动推送与手动发布使用同一份表，图片内容一致。推送规则见 [活动规则与发布](publish.md)。

## 空值说明

发布图中创作者栏为空，是因为未猜出的符卡不显示创作者。该符卡被猜出后重新发布，创作者栏会出现名字。

某创作者未出现在剩余表中，是因为该创作者名下符卡的创作者栏为空，这些符卡无法归属，不计入该表，两张表的行数也会不一致。需要在 [对应表与别名表](../guessing/tables.md) 中补齐创作者。
