# 导出合并工程

导出将对应表与创作者包的内容合并进模板，生成可打包的工程、mod zip 与三列对应表。

## 导出条件

- 模板路径与输出路径均已填写。任一为空时，右下列表显示「[错误] 请先设置模板路径与输出目录」，不生成任何产物。
- 输出目录应为独立目录或空目录，避免与上一轮产物混淆。
- 需要生成 mod zip 时，Sharp 目录与插件 dll 必须已填写；未填写时仍会导出工程与对应表，但不生成 zip。
- 建议先备份模板，并用一两个包在副本上试导一次。

## 合并模式

「合并模式」下拉框提供两个选项。

![导出选项与输出路径](images/merge-export-1.png)

上图为导出区，「合并模式」下拉框、五个选项与输出路径均在此处。

| 模式                 | 方式                                                                           | 适用                     |
| -------------------- | ------------------------------------------------------------------------------ | ------------------------ |
| 提取式（按类型重放） | 符卡、资源、对象按类型抽出，分别重放到对应注入点，创作者原有的文件夹结构被打散 | 默认选项                 |
| 按顶层文件夹整搬     | 以包根下最靠近根目录的顶层文件夹为单位整体搬入对象注入点，不使用资源注入点     | 投稿带有完整文件夹结构时 |

两种模式的差别在于是否展开文件夹。提取式将各包内容按类型重放，结构较为平整；整搬保留创作者原有的目录结构。

> **注意**：整搬模式下，模板中已存在的同名顶层文件夹不会被覆盖，以模板内容为准。名为 `Name` 的文件夹例外，即使模板中存在同名文件夹也会搬入。资源注入点在该模式下不参与合并。

## 导出选项

| 选项                                          | 启用后的行为                                                                   |
| --------------------------------------------- | ------------------------------------------------------------------------------ |
| 导出包含 `.lstges` 工程文件                   | 将合并工程 `mod.lstgproj` 写入输出目录；未启用时工程仅存在于临时目录，用于打包 |
| 混淆 Lua 脚本                                 | 记录该选择；当前版本的导出流程不包含混淆步骤，产物不会被混淆                   |
| 冲突自动改名                                  | 同名资源按「包名\_原名」改名，避免互相覆盖；未启用时保留原名并在冲突列表中列出 |
| 前置对话/移动的符卡强制按 Perform Action 整合 | 紧邻前序为对话或出场移动的符卡会把前序一同注入，练习模式不缺少前置阶段         |
| 按创作者分组（每人专属文件夹）                | 注入资源与对象时按创作者创建文件夹；不影响符卡注入点，且仅对提取式生效         |

「混淆 Lua 脚本」不改变产物内容，导出流程中没有对应步骤，该选项只保存选择。「前置对话/移动的符卡强制按 Perform Action 整合」适用于练习模式下无法进入的符卡：启用时注入紧邻前序，未启用时只按符卡自身声明的属性处理。

## 导出完整包

![冲突/日志列表与导出结果](images/merge-export-2.png)

上图为右下的冲突与结果列表。

1. 按对应表顺序将内容合并进模板。
2. 按第一个选项决定是否写出工程文件，并将引用的贴图、音频按相对路径复制到输出目录。
3. 调用 Sharp 打包，再在同一目录导出对应表 CSV。

冲突与结果显示在右下列表中，每行以方括号开头：`[Resource]`、`[Object]` 表示冲突类别，`[打包]`、`[完成]`、`[失败]`、`[错误]` 表示执行阶段。出现多条 `[Resource]` 表示多个包使用了同名资源，处理方式有两种：启用「冲突自动改名」重新导出，或手动调整文件名。

产物名默认为 `mod`：目录中包含 `mod.zip`（已填写 Sharp 时）、`mod.lstgproj`（启用工程文件选项时）与固定名称的 `spellcard_mapping.csv`。

## 导出对应表

「导出对应表」只写出 `spellcard_mapping.csv`，不涉及工程文件。对应表顺序调整后，可以用该方式单独更新 CSV。

三列固定为 `Boss`、`符卡名`、`创作者`，首行为表头。非符行的符卡名写为「非符」；Boss 列取模板中的 Boss 显示名，无法获取时写为「共同Boss」。文件编码为 UTF-8 且不带 BOM，用 Excel 直接打开时中文可能显示为乱码，需通过「数据 → 从文本/CSV」按 UTF-8 导入。
