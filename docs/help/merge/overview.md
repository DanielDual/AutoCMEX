# 整合板块概览

整合板块把多名创作者提交的 LuaSTG 工程合并为一个可发布的整体，并生成符卡与创作者的对应表。合并结果可打包发布，对应表供猜测板块使用。

## 前置条件

开始前需要准备：

- 模板工程 `.lstgproj`，其中保留三处注入点注释（见 [模板与注入点](template.md)）。
- LuaSTG Editor Sharp 的安装目录，包含 `LuaSTGEditorSharp.Core.Cli.exe`。
- 编译插件 dll 的文件名，通常为 `LuaSTGPlusLib.dll`。
- 每位创作者一个 `.zip` 包，包内含 `.lstges` 工程。

路径与勾选项在修改后自动保存，重启程序仍然有效；更换机器或移动目录后需要重新填写。

## 操作顺序

1. 导入创作者包。包内的符卡、资源与对象会解析为三份清单。
2. 填写模板、Sharp 与插件 dll 三条路径，点击「导入并检测注入点」，确认状态行的检测结果。
3. 检查对应表顺序，必要时重排（见 [对应表与排序](correspondence.md)）。
4. 选择合并模式与导出选项。
5. 点击「导出完整包」；只需要对应表时点击「导出对应表」。

导入创作者包失败时不会弹出提示，原因记录在日志中，包列表也不会新增条目。导入后应确认列表是否发生变化，细节见 [导入创作者包](import-package.md)。

## 界面分区

整合板块分为四个区域：左上为创作者包与三类清单，左下为模板配置，右上为符卡与创作者的对应表，右下为导出选项与冲突列表。

![整合板块四区总览](images/merge-overview-1.png)

导出过程中的冲突、警告与结果都显示在右下列表中。每行以方括号开头：`[Resource]`、`[Object]` 表示冲突类别，`[完成]`、`[失败]`、`[错误]` 表示执行阶段。

## 输入与输出

输入为创作者提交的 zip 包和模板工程。输出包括合并后的工程（产物名默认为 `mod`，含 `mod.zip`、`mod.lstgproj` 等文件）与三列对应表 `spellcard_mapping.csv`。

对应表的行序即导出顺序，导出前应再核对一次。
