# 录制设置

录制设置位于设置板块「信息」类别页底部，包含引擎目录、录制插件、并行度、沙箱根目录与高级参数。这些参数决定录制能否启动，以及产物的分辨率、体积与录制耗时。

## 入口

设置板块「信息」类别页最下方为「符卡 GIF 录制设置」，默认折叠，勾选标题后展开。每次展开时重新检查状态，修改引擎目录后无需重启程序。

## 引擎目录

引擎目录为 LuaSTG 根目录：包含 `game/`，且 `game/` 中包含 `launch` 文件。可通过「选择目录…」手动选择，或通过「从 Sharp 目录推断」按整合板块的 Sharp 目录向上查找。

![录制设置整组展开](images/recording-settings-1.png)

「从 Sharp 目录推断」依赖整合板块中已填写的 Sharp 目录；未填写时该按钮禁用，需先在 [模板与注入点](../merge/template.md) 中设置。状态行有三种：

| 状态行                                  | 含义                                                   |
| --------------------------------------- | ------------------------------------------------------ |
| 未设置引擎目录：…                       | 尚未填写                                               |
| 引擎目录无效：…（随后是原因）           | 目录不存在、缺少 game/ 或缺少 launch                   |
| 引擎目录可用，可执行文件：LuaSTGSub.exe | 可用（绿色）；提示未找到 `LuaSTGSub*.exe` 时应确认版本 |

状态行为绿色时表示目录可用。非法目录不会被保存，输入框恢复原值，原因显示在该组最下方的操作提示行。

## 录制插件

录制需要两个插件：应用自带的 `autocmex` 与第三方插件 `danmaku_recorder`。两行状态分别为以下四种之一：已安装并启用、已安装但被禁用、未安装、插件清单损坏。插件清单损坏时，部署按钮全部禁用，需要先修复清单。

- 「安装并启用 autocmex」将自带插件复制到引擎目录并登记为启用；已安装时可再次执行，用于升级后刷新。
- 「启用弹幕录制器」仅将清单条目改为启用，不修改文件；第三方插件需自行放入引擎的 `plugins/` 目录。
- 「重新检查」重新读取状态，可在更换文件后使用。

两行状态均为已安装并启用时，才具备录制条件。安装与启用仅在点击按钮时写入引擎目录；打开面板不会修改文件。修改插件清单前应备份。

## 并行度与沙箱

并行度为同时运行的引擎实例数，范围 1~32，默认 16。实际 worker 数为并行度与战斗卡数中的较小值：战斗卡为 4 张时，并行度设置为 16 也只启动 4 个。

沙箱根目录为空时使用系统临时目录；手动指定的目录必须已存在。每轮为每个 worker 创建一份引擎副本，占用空间随并行度增加。空间提示显示「单 worker 约 X × 并行度 N = 约 Y」与所在卷的剩余空间；空间不足时仅提示，不阻止保存，录制启动时自动下调并行度，降至 1 仍不足时中止。

## 高级参数

四项参数的范围与默认值：

![高级参数四项与换算说明](images/recording-settings-2.png)

| 参数       | 范围           | 默认 | 说明                              |
| ---------- | -------------- | ---- | --------------------------------- |
| 帧数上限   | 1~1000         | 350  | 每张卡的帧数预算                  |
| 首次间隔   | 1~60           | 3    | 帧率 = 60 ÷ 间隔，3 约 20 fps     |
| 换挡后间隔 | 1~60           | 5    | 5 约 12 fps                       |
| 放缩比 (%) | 10~100，步进 5 | 50   | 决定分辨率与体积，50 即宽高各减半 |

换挡规则：首次录制录满帧数上限被截断，或首次产物达到 30MB 时，以「换挡后间隔」重录一次，采用第二次的产物；第二次仍超过 30MB 时不再进行第三次，照常采用。

数值越界时自动收敛到区间内，不会保存非法值。页面底部显示「上次输出目录」，用于查找上一轮产物。
