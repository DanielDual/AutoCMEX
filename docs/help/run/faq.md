# 常见问题

以下按现象归类常见问题，每条给出处理方向，细节见对应页面。

## 上手与数据

**第一次使用时应先完成哪些步骤？** 按 [快速开始](../start/getting-started.md) 的步骤完成最短流程：导入包、导出、导入对应表、发布一次信息。之后对照 [术语与活动流程](../start/concepts.md)，确认五个阶段与板块的对应关系。

**数据保存在哪里，如何备份？** 保存在用户数据目录。退出程序后将整个目录复制即可；迁移到其他机器时放回同一位置。路径、密钥文件与迁移注意事项见 [数据存放与备份](../start/data-and-backup.md)。

**无网络时能否使用？** 整合、手动判定与图片生成在本机执行。模糊化处理需要连接 AI 服务，群聊托管需要连接 Koishi；两者未配置或无网络时，仅能使用本机功能。

## 整合

**导入创作者包失败？** 仅支持 `.zip`，包内需包含 `.lstges` 工程。失败时不弹出提示，原因写入日志，包列表也不会新增条目。导入后应确认列表是否变化，原因见 [导入创作者包](../merge/import-package.md)。

**导出的工程在 Sharp 中无法打开？** 核对模板、注入点状态与导出选项，并查看右下角的冲突与日志列表。常见原因为模板或注入点未正确配置，见 [导出合并工程](../merge/export.md)。

**对应表 CSV 打开后为乱码？** 文件编码为 UTF-8。在 Excel 中使用「从文本/CSV」导入并选择 UTF-8 编码，不应直接双击打开。

## 猜测

**「模糊化处理」按钮为禁用状态？** 当前没有可用的 AI 模型。在设置中配置模型并完成测试连接，再于「激活模型」中选中，见 [AI 模型](../settings/ai-models.md)。

**群聊中的猜测未收到回应？** 先确认 [WebSocket 状态面板](websocket.md) 存在连接，再核对消息是否符合当前消息筛选方式，以及是否进入丢包列表。任一条件不满足，群内都不会收到回应。

**为什么回应「必须猜两个以上」？** 有效猜测只统计尚未猜出的符卡，不足两张时返回该回应；若为 0 张且全部已猜出，则返回另一条回应。完整规则见 [猜测文本与回应规则](../guessing/syntax.md)。

**丢包应如何处理？** 点击「重试全部丢包」逐条重放。仅当回帖成功发送后，记录才会移除；链路未运行、未能发送或重放失败时，记录保留，可在稍后重试。见 [丢包与重试](../guessing/dropped.md)。

## 信息与发布

**发布只完成了一部分？** 一键转发按固定顺序逐项执行，失败即停止。结果对话框会列出未发送项，并提供「只重试失败项」，见 [活动规则与发布](../info/publish.md)。

**刷新群列表失败？** 表示当前没有可用的 Koishi 连接。先查看 [WebSocket 状态面板](websocket.md)，连接后再执行刷新。

**GIF 集导入失败？** 清单与目录中的图片必须一一对应，数量不一致时整体拒绝导入，弹窗会逐条列出原因，见 [符卡 GIF 集](../info/gif-set.md)。

**统计表中的创作者栏为空？** 未猜出的符卡不显示创作者，避免在群内提前透露答案，属正常表现，见 [两张统计表](../info/tables.md)。

**已猜出的符卡仍出现在表中？** 猜测表列出当前 Boss 的全部符卡，已猜出的行整行标绿，不会被移除。

**「猜测表变化自动推送」没有反应？** 该功能默认关闭。需要勾选该选项，并在下栏勾选目标群；内容变化后约 1.5 秒发送，见 [活动规则与发布](../info/publish.md)。

## 录制

**点击「录制」后没有开始？** 前置检查（引擎目录、插件、沙箱根）未通过时只说明原因，不启动任何进程。按提示处理后重试，见 [录制设置](../recording/settings.md)。

**录制耗时长、占用磁盘多？** 每张卡至少启动一次引擎，每个 worker 各有一份引擎副本。降低并行度、帧数上限或放缩比可减少时间与空间占用，见 [录制设置](../recording/settings.md)。

**录制完成的 GIF 在集内无法打开？** 卡片会显示「GIF 加载失败（…）：原因」，发布前预检也会拦截缺失或空文件，见 [符卡 GIF 集](../info/gif-set.md)。

**插件状态显示清单损坏？** 该状态下程序不提供任何部署操作。按 [录制设置](../recording/settings.md) 的说明处理，不应手工修改清单。

## 群聊与帮助

**Koishi 控制台中搜索不到插件？** 在控制台「添加插件」中搜索 `adapter-autocmex`，或查看「适配器」分类；同时确认插件已安装并启用，见 [群聊连接与 Koishi](../settings/chat.md)。

**WebSocket 反复断开、两端互相踢？** 同进程多实例互踢问题已在本版本修复。若仍反复断开，查看面板错误行与 [日志](logging.md)；连接期间不宜修改连接设置。

**如何查找所需内容？** 顶栏的「搜索」按钮（Ctrl+K）可跨页检索；也可按板块从概览页进入，页内「相关」列出相邻主题。

**帮助内容与界面不一致？** 以当前版本界面为准；可记录页面标题与界面文案并交由维护者核对。
