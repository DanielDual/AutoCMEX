# 信息类别与目标群

目标群决定信息板块（[信息板块概览](../info/overview.md)）的发布对象，在设置页的「信息」类别中维护。该页底部同时提供符卡 GIF 录制设置，整组常显。

## 目标群列表

每一行包含启用勾选框、群 ID 输入框、「展示名（可留空）」输入框与「删除」按钮。

![目标群列表与添加/刷新](images/settings-info-1.png)

图中为目标群列表与底部的添加、状态行区域。

勾选框即「启用」。信息板块的发布对象就是这些启用项，发布时以本页为准；信息板块不再提供勾选入口。

群 ID 是 Koishi 使用的频道标识，不是群名称。群 ID 在回车或失焦时写回；输入为空或与已有项重复时保留原值，并在状态行说明原因。群 ID 可通过本页的「刷新群列表」自动获取，也可参照 Koishi 侧的配置手工填写。

展示名仅用于界面显示，可留空，不参与发送。群 ID 与展示名不一致时，以群 ID 为准。

状态行显示「共 N 个目标群（启用 M 个）。」；未配置时显示「尚未配置目标群。」。「启用」即勾选状态，与发布时使用的条件一致。点击某行的「删除」会将该群从列表移除，后续发布不再包含该群；已发送的内容不受影响。

## 添加与刷新

「添加目标群」在列表末尾新增一行，默认处于勾选状态，群 ID 为空，需要手工填写。

「刷新群列表」位于本页目标群列表上方。该操作向 Koishi 请求群列表，并将新出现的群加入配置：新群默认不启用，已有群的启用状态与展示名保持不变。未连接 Koishi 时刷新会直接失败，不会静默处理。

> **注意**：刷新群列表产生的群默认不启用，避免一次刷新将内容发送到全部群。刷新后应在本页确认启用状态，再进行发布。

## 录制设置入口

页面底部的「符卡 GIF 录制设置」整组常显，随页面纵向滚动查看（目标群列表保留自己的滚动区域，不会被撑长）。每次进入本页都会重新检查引擎目录与插件状态，避免沿用上一次的状态。可配置引擎目录、并行度、沙箱目录、插件与高级参数，各项说明见 [录制设置](../recording/settings.md)。

## 与信息板块的关系

本页管理目标群列表及其启用状态，发布的群就是这里启用的群（发布规则见 [活动规则与发布](../info/publish.md)）。更换活动群后，在本页添加群或修改群 ID 并启用即可。

「刷新群列表」在本页执行，结果直接并入本页列表。目标群数据随配置文件保存，迁移整个数据目录后无需重新配置。

## 常见问题

群 ID 填写错误：该群收不到发布内容，界面其他位置不会提示。可对照 Koishi 侧的信息核对，或通过「刷新群列表」重新获取。

刷新群列表无响应：确认 Koishi 已连接，并查看 [WebSocket 状态面板](../run/websocket.md) 与 [日志](../run/logging.md) 中的请求记录。

列表中存在多个群但发布未送达：发布使用本页启用的群，而非列表中的全部群。
