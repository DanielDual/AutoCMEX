# 设置板块概览

AutoCMEX 的配置集中在左栏「设置」页，包括 AI 模型、群聊连接、目标群与录制参数。配置按类别分页，选中左侧类别后，右侧显示该类别下的配置项。

## 页面结构

设置页分为搜索栏、类别列表与配置项三部分。切换类别不会清除已填写的内容，返回时仍为原值。

![设置板块三区布局](images/settings-overview-1.png)

图中为搜索栏、左侧类别列表与右侧配置项的布局。

搜索栏按类别名过滤：输入「群」时保留「群聊」，输入「端口」不会产生匹配，因为该搜索不检索类别内的配置项。清空搜索框后，全部类别恢复可选。

## 类别

左栏类别固定为「AI模型」「群聊」「猜测」「整合」「信息」「帮助」「通用」，与当前所在板块无关。当前只有「AI模型」「群聊」「信息」三个类别包含配置项，其余类别右侧为空；「帮助」同为空类别，不指向本手册页面。

| 类别     | 配置内容                                        | 说明页                       |
| -------- | ----------------------------------------------- | ---------------------------- |
| AI模型   | 激活模型、请求超时、模型列表                    | [AI 模型](ai-models.md)      |
| 群聊     | 端口、连接模式、Koishi 地址、消息筛选、插件安装 | [群聊连接与 Koishi](chat.md) |
| 信息     | 目标群列表、符卡 GIF 录制设置                   | [信息类别与目标群](info.md)  |
| 其余四类 | 无配置项                                        | 对应板块页面                 |

对应表、别名表与活动规则不属于设置，由各板块单独维护。

## 保存与生效

设置页没有保存按钮，修改后约一两秒自动写入。多数控件修改后立即生效；地址与群 ID 等文本输入框在回车或失焦时写回，避免输入过程中反复保存与重建连接。数值框超出范围时收敛到区间内，例如端口输入 70000 会变为 65535。

群聊的端口、模式与地址每次修改都会重建连接，重建期间连接中断。发布过程中不宜修改这些配置。

> **注意**：修改后立即退出程序，尚未写入的修改可能丢失。退出前应留出一两秒。

## 何时需要修改

更换 AI 服务商时，修改模型的地址与密钥，并重新选择激活模型。更换活动群时，在「信息」类别添加群或修改群 ID。更换机器时，若整个用户数据目录一并迁移，配置可直接使用；仅迁移程序则需要重新配置。数据目录位置与备份方式见 [数据存放与备份](../start/data-and-backup.md)。

设置不提供恢复默认值的功能，修改后需要手工改回原值。修改前记录旧值或备份数据目录可以减少返工。第二场活动沿用同一套配置时，设置部分通常无需修改；对应表、别名表与活动规则是否沿用，由各板块自行决定。

## 与其他板块的关系

设置本身不产生内容。模型决定模糊化与智能匹配是否可用，群聊参数决定群消息能否进入程序，目标群决定信息板块的发布对象。出现问题时，可先确认相关设置项是否为空。
