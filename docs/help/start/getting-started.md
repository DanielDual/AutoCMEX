# 快速开始

AutoCMEX 的首次使用包括运行程序与走通一次最短流程。AI 模型与群聊连接可以在流程走通后再配置。

## 运行方式

有两种方式，任选其一。

发布版：运行 `AutoCMEX.exe`。

从源码运行：需要 Windows、Godot 4.7.1（.NET 版）与 .NET 8 SDK。用 Godot 打开项目中的 `project.godot` 运行，或在项目目录执行 `godot --path .`。

程序数据不保存在安装目录，首次运行时会创建用户数据目录；升级、重装或删除程序不会修改该目录。目录位置与内容见 [数据存放与备份](data-and-backup.md)。

## 界面结构

左栏为板块导航：顶端为 AutoCMEX 标识，中部为「整合」「猜测」「信息」，下部为「设置」「帮助」「日志」「WebSocket」，底部显示版本号。右栏为当前板块的工作区。启动后默认停留在「猜测」板块，未导入数据时表格与输入框为空。

![主窗口总览：左栏导航与右栏工作区](images/start-getting-started-1.png)

上图为主窗口布局：左栏为导航，右栏为当前板块的工作区。

切换板块只改变右栏内容，各板块的状态会保留。例如在整合板块导入包后切换到其他板块，返回时包列表仍然存在。

## 最短流程

以下顺序覆盖三个主要板块。AI 模型与群聊连接可以跳过，手动输入猜测即可完成流程。

1. 在「整合」板块点击「导入创作者包」；按 [模板与注入点](../merge/template.md) 填写三条路径，点击「导入并检测注入点」确认结果，再点击「导出完整包」。
2. 在「猜测」板块点击「导入对应表」与「导入别名表」，导入整合导出的三列 CSV，并在下拉框中选中当前 Boss。
3. 需要群聊猜测自动进入程序时，在「设置」的「AI模型」中配置可用模型，并在「群聊」中完成 Koishi 连接。
4. 在「信息」板块（[信息板块概览](../info/overview.md)）导入符卡 GIF 集或使用 [录制](../recording/overview.md) 生成，填写活动规则、勾选目标群，然后逐栏发布或使用一键转发。
5. 活动开始后回到「猜测」板块处理猜测与丢包；信息板块的两张统计表会随判定结果更新。

## 常见阻塞

以下三处会导致功能不可用，界面上均会给出原因。

「模糊化处理」按钮为禁用状态：尚未选中有效的 AI 模型，配置方法见 [AI 模型](../settings/ai-models.md)。

群聊中的猜测没有回应：连接状态见 [WebSocket 状态面板](../run/websocket.md)。

点击「录制」时提示「暂时无法录制」：引擎目录或录制插件不满足条件，检查项见 [录制设置](../recording/settings.md)。

配置、对应表、别名表、GIF 集与加密后的密钥保存在用户数据目录的 `data` 文件夹；日志与录制产物位于其他位置。
