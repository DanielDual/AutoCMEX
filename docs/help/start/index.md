# 帮助中心

本手册说明 AutoCMEX 的使用方法，内容与当前版本的功能一致。开始使用前，建议先读 [快速开始](getting-started.md)；之后按需要查阅对应板块的页面。

AutoCMEX 是面向 CMEX 活动组织者的桌面工具，用于整合创作者提交的 LuaSTG 工程、托管群聊中的猜测，以及把符卡 GIF 与统计表发布到活动群。创作者无需安装。

## 使用路径

- 首次使用：先读 [快速开始](getting-started.md) 走一遍最短流程，再读 [术语与活动流程](concepts.md) 统一术语。
- 组织活动：按 整合 → 猜测 → 信息 的顺序阅读。整合产出的对应表是猜测与信息板块的输入。
- 排查问题：先查 [常见问题](../run/faq.md)，需要细节时看 [日志](../run/logging.md) 或 [WebSocket 状态面板](../run/websocket.md)。

左侧导航按板块组织，顶栏的「搜索」按钮（Ctrl+K）支持跨页检索。帮助内容随版本更新；若界面与文字不一致，以当前界面为准。
