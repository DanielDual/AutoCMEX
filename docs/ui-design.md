# AutoCMEX — UI 设计规范

## 全局布局

### 主窗口布局

项目主窗口采用 **左右两栏** 布局，左窄右宽，窗口可自由缩放：

```
┌──────────────────────────────────────────┐
│  ┌──────────┐  ┌──────────────────────┐  │
│  │          │  │                      │  │
│  │  左栏    │  │       右栏           │  │
│  │  (窄)   │  │       (宽)           │  │
│  │          │  │                      │  │
│  │          │  │                      │  │
│  └──────────┘  └──────────────────────┘  │
└──────────────────────────────────────────┘
```

### 左栏布局

左栏用于切换功能板块，从上到下依次为：

| 位置      | 内容                           |
| --------- | ------------------------------ |
| 顶端      | 项目 Logo（暂用占位图标）      |
| Logo 下方 | 功能板块按钮：整合、猜测、信息 |
| 底端上方  | 功能板块按钮：设置、帮助       |
| 最底端    | 版本号                         |

```
┌──────────┐
│  Logo    │  ← 顶端
│──────────│
│  整合    │
│  猜测    │  ← 主要功能板块
│  信息    │
│          │
│          │  ← 弹性空白区域
│          │
│──────────│
│  设置    │
│  帮助    │  ← 辅助功能板块
│──────────│
│  v1.0.0  │  ← 版本号（最底端）
└──────────┘
```

### 右栏布局

右栏展示当前选中功能板块的内容。所有板块场景在启动时全部预加载，切换时通过显隐控制，各板块维护独立的 `.tscn` 文件。

### 猜测板块

猜测板块右栏顶部有 Boss 下拉选择框（默认选中第一个 Boss），下方分为三区域：

```
┌──────────────────────────────────────────┐
│  Boss: [下拉选择框                   ▼]  │
├──────────────────────────────────────────┤
│  ┌─────────────────┐ ┌────────────────┐  │
│  │  符卡—创作者    │ │                │  │
│  │  对应表         │ │  猜测文本      │  │
│  │  (Tree 控件)    │ │  输入框        │  │
│  │                 │ │                │  │
│  │  [按钮区]       │ │  [模糊化处理]  │  │
│  ├─────────────────┤ ├────────────────┤  │
│  │  创作者别名表   │ │  回应显示栏    │  │
│  │  (树状结构)     │ │                │  │
│  │                 │ │                │  │
│  │  [按钮区]       │ │                │  │
│  └─────────────────┘ └────────────────┘  │
└──────────────────────────────────────────┘
```

| 区域      | 位置     | 内容                                                    |
| --------- | -------- | ------------------------------------------------------- |
| Boss 选择 | 顶部     | 下拉框，切换当前被猜测的 Boss                           |
| 左上      | 左侧上方 | 符卡—创作者对应表（Tree 控件，仅显示当前 Boss）         |
| 左下      | 左侧下方 | 创作者别名表                                            |
| 右        | 右侧     | 上方为猜测文本输入框 + 模糊化处理按钮，下方为回应显示栏 |

- 左上和左下之间为可拖拽分割线（VSplitContainer）。
- 功能按钮（导入、导出、添加、删除）放置在对应栏目旁。
- 从工程文件导入按钮预留但禁用，hover 提示"功能开发中"。
- 未配置 AI 模型时，模糊化处理按钮禁用，hover 提示"请先配置 AI 模型"。

### 信息板块

上栏为四栏横向排布（内容超出可视宽度可横向滚动），下栏为目标群聊与发布操作：

```
┌────────────────────────────────────────────────────────────┐
│ ┌────────────┬────────────┬────────────┬────────────┐      │
│ │ 符卡 GIF 集 │符卡猜测情况│创作者剩余未 │  活动规则   │  →   │
│ │ [集▾][导入] │    表      │被猜测符卡数│            │      │
│ │            │            │    表      │            │      │
│ │ ┌────────┐ │ ┌────────┐ │ ┌────────┐ │ ┌────────┐ │      │
│ │ │1.符卡名│ │ │表格预览│ │ │表格预览│ │ │文本编辑│ │      │
│ │ │ (动图) │ │ │        │ │ │        │ │ │        │ │      │
│ │ └────────┘ │ └────────┘ │ └────────┘ │ └────────┘ │      │
│ │  [发布]    │  [发布]    │  [发布]    │  [发布]    │      │
│ └────────────┴────────────┴────────────┴────────────┘      │
│ ┌────────────────────────────────────────────────────────┐ │
│ │ 目标群聊 [☑群A] [☐群B] …   [刷新群列表]  [一键转发]    │ │
│ └────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```

| 区域         | 位置     | 内容                                                                              |
| ------------ | -------- | --------------------------------------------------------------------------------- |
| 上栏         | 上方     | ScrollContainer 横向滚动 + 内层 HBoxContainer 装四栏（Godot 无 HScrollContainer） |
| GIF 集栏     | 上栏第一 | 集切换下拉、导入文件夹/导入压缩包、录制、卡片列表、发布                           |
| 猜测表栏     | 上栏第二 | 表格预览（与发布图同源）+ 发布                                                    |
| 创作者剩余栏 | 上栏第三 | 表格预览 + 发布                                                                   |
| 活动规则栏   | 上栏第四 | 纯文本编辑 + 发布                                                                 |
| 下栏         | 底部     | 目标群聊多选列表 + 刷新群列表 + 一键转发                                          |

- GIF 集卡片为「`序号. 符卡名`」标题 + 下方动图；列表懒加载，只播放视口内可见的少数几张。
- 录制按钮点击后依次为前置检查（引擎目录 / 插件可录制性 / 沙箱根，不通过则只说明原因且不弹任何选择框）→ 手选工程包 zip → 手选输出目录 → 起录；运行期间弹出进度对话框（阶段 + 已完成/失败/总数 + 各 worker 正在录的卡 + 取消），录完自动把输出目录导入为本栏的集并选中。hover 提示由代码在运行时设置（场景里仍是占位文案）。
- 栏内无可发布内容（集内 0 张 / 当前 Boss 无符卡 / 活动规则为空）或该栏正在发布时，其「发布」按钮禁用。
- 未勾选任何目标群或正在发布时，「一键转发」禁用。
- 「刷新群列表」向 Koishi 查询群列表并并入本地（新并入的群默认不勾选）；与 Koishi 无连接时弹窗提示刷新失败。
- 发布结果通过对话框呈现（逐项成功/失败与原因、失败即停时列出未发送项）；存在失败项时对话框提供「只重试失败项」按钮。

#### 群聊类别页（WebSocket 与 Koishi）

「群聊」类别页自上而下是：WebSocket 端口 → 模式（Server / Client）→ Koishi 地址（仅 Client 模式显示）→ 消息过滤模式 → 「一键安装 Koishi 插件」 → 插件状态行。

| 元素        | 形态                           | 交互与状态                                                                                      |
| ----------- | ------------------------------ | ----------------------------------------------------------------------------------------------- |
| 端口        | 数字输入（1–65535）            | 改动即写回设置并触发自动保存                                                                    |
| 模式        | 二选一下拉                     | Server = 本机监听端口；Client = 主动连接 Koishi 地址                                            |
| Koishi 地址 | 单行输入（仅 Client 模式显示） | **回车提交或失焦时写回**（去首尾空白）；写入后由设置绑定链路重建连接；地址为空不会回落成 Server |
| 插件状态行  | 自动换行文本                   | 「插件状态: 未安装…」或「插件状态: 已安装到 `<路径>`」，路径取自设置，重启后仍可见              |

页面每次显示时重新从设置同步一次；同步期间控件回发的变化会被忽略，避免只是翻到这一页就白白自动保存一次。

#### 信息类别页的录制设置

「信息」类别页自上而下是：目标群列表 → 添加入口 → 说明 → 状态行 → **符卡 GIF 录制设置**（默认折叠的整组开关，避免挤压上方的目标群列表）。展开后的分组布局：

```
┌ 符卡 GIF 录制设置 ───────────────────────────────┐
│ 引擎目录（LuaSTG 根目录，含 game/ 与 doc/）        │
│ [D:\LuaSTG            ] [选择目录…] [从 Sharp 推断]│
│ 引擎目录可用，可执行文件：LuaSTGSub.exe            │
│ 并行录制的引擎实例数 [ 4] 实际 worker = min(…)，…  │
│ ──────────────────────────────────────────────── │
│ 沙箱根目录（每轮为每个 worker 建一份引擎副本…）     │
│ [                      ] [选择目录…] [恢复默认]    │
│ 沙箱根：… / 单 worker 约 1.2 GB × 并行度 4 = …    │
│ ──────────────────────────────────────────────── │
│ 录制插件（安装与启用只在你点击按钮后写入引擎目录）  │
│ autocmex：未安装（应用自带，可一键安装）            │
│ danmaku_recorder：未安装（第三方插件…）            │
│ [安装并启用 autocmex] [启用弹幕录制器] [重新检查]  │
│ ──────────────────────────────────────────────── │
│ 高级参数                                          │
│ 帧数上限 [350] 首次间隔 [3] 换挡后间隔 [5] 放缩比 [50]│
│ 间隔 3 ≈ 20 fps、5 ≈ 12 fps；长卡在帧数上限处截断… │
│ 上次输出目录：… / 已更新为 350。                   │
└──────────────────────────────────────────────────┘
```

| 元素         | 形态                 | 交互与状态                                                                                                           |
| ------------ | -------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 组开关       | 复选框（默认未勾选） | 勾选才显示主体；每次展开顺带刷新一次状态                                                                             |
| 目录输入     | 单行输入 + 两个按钮  | 输入在提交/失焦时写回；非法目录保留原值并在状态行说明原因                                                            |
| 状态行       | 自动换行文本         | 可用为绿、需处理为橙；文案即工具提示，不额外弹窗                                                                     |
| 数值框       | 步进 1 的数值框      | 越界输入收敛到区间；并行度 1~32、帧数上限 1~1000、间隔 1~60、放缩比 10~100（步进 5，单位 %）                         |
| 部署按钮     | 依赖状态启停         | 清单损坏或引擎目录未就绪时禁用（清单**缺失**不禁用，安装会把清单建出来）；自家插件已安装时仍可「重装」（升级后刷新） |
| 操作结果提示 | 组内最后一行         | 只在有内容时占位，显示最近一次操作的结果或被拒原因                                                                   |

目录选择用系统目录对话框（只选目录）。面板不做实时校验风暴：状态行只在展开、切换配置、每次操作后重算。

### WebSocket 状态面板

右栏的 WebSocket 页面显示**当前实例**的真实状态（一律取自 `IWebSocketServer` 的 `Mode`/`Port`/`Url`/`LastError`，不取自设置——设置改动后实例重建前两者可能短暂不一致）：

| 位置       | 内容                                                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 模式行     | `模式: Server（等待连接）` / `模式: Client（主动连接）`                                                                         |
| 状态行     | 前缀 `状态: ` 是场景里的独立标题，值只有状态本身：Server `运行中` / `已停止`，Client `已连接` / `未连接`，并按运行与否着绿 / 红 |
| 端口行     | Server 模式为 `端口: <实际监听端口>`；Client 模式为 `地址: ws://…`（含 Token 的完整对端地址）                                   |
| 连接数行   | 仅 Server 模式显示 `连接数: N`；Client 只有一条链路、与状态行重复，整行隐藏                                                     |
| 事件行     | 最近一次连接/断开等事件                                                                                                         |
| 错误行     | 红色自动换行文本，显示最近一次启动/运行失败的原因（如「未配置 Koishi 地址」）；无错时隐藏                                       |
| 开关按钮   | Server：启动 / 停止；Client：连接 / 断开                                                                                        |
| 客户端列表 | 标题随模式变（`已连接客户端:` / `连接的对端:`），内容每秒与实例同步一次                                                         |

## 设计原则

1. **左窄右宽**：左栏仅用于导航，右栏为主要工作区。
2. **板块隔离**：切换板块时右栏内容完全替换，各板块 UI 独立。
3. **一致性**：同类操作的按钮风格保持一致。
4. **响应式**：窗口缩放时右栏自适应，左栏保持固定宽度。
5. **状态反馈**：不可用功能以禁用态展示并给出 hover 提示，导入失败弹窗告知具体错误。
